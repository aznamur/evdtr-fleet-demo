# FleetOps — Portfolio Case Study

## Problem

Fleet operations involve activity records across travel, utilization, idle time, and equipment breakdowns. Reviewing these manually makes it harder to spot delays and anomalous readings.

## Demo solution

An interactive web dashboard with fleet KPIs, operational charts, activity logs, route summaries, wait monitoring and outlier review.
